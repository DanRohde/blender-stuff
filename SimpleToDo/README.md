This simple Add-on allows you to manage tasks and track time.

## Quick Start Guide
1. Install and enable the SimpleToDo add-on
2. Add some tasks:
   - open 3D Viewport: Press 'N' > Tasks > SimpleToDo
   - press "Add Task"

## Features
- Simple task management with two statuses: to do and done.
- Simple time tracking
- Setting task priorities.
- Quick Add feature: If enabled in the add-on preferences, you can add new tasks via the top bar.
- Quick Task Actions feature: You can manage your tasks in the top bar.
